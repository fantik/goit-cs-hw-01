# Архітектура комп'ютерів, домашка 1

Два окремі завдання. Перше — програма на асемблері, друге — інтерпретатор на Python.

## Завдання 1

Файл: `task1.asm`

У конспекті програма рахує `a + b - c`. Тут той самий приклад, тільки порядок інший: `b - c + a`.

Значення ті самі, що в конспекті: `a = 5`, `b = 3`, `c = 2`.

`3 - 2 + 5 = 6`. Результат запуску в DOSBox — на скріншоті `task1-dosbox.png`: `Result: 6`.

## Завдання 2

Файл: `task2.py`

Взято інтерпретатор з конспекту (додавання і віднімання) і додано множення, ділення та дужки.

Спочатку рахуються дужки, потім `*` і `/`, потім `+` і `-`.

Запуск:

```
python3 task2.py
```

Ввести вираз, наприклад `(2 + 3) * 4`. Має вийти `20`. Вихід — `exit`.
